## Project Overview

Eidaah is an AI-powered educational website that helps learners better understand their uploaded study materials through AI-generated summaries and explanations.

The project focuses on making learning more accessible and providing a clear, user-friendly study experience.

## Key Features

- Upload study materials for AI-assisted learning.
- Generate summaries of educational content.
- Provide AI-powered explanations to support understanding.
- Offer a user-friendly learning interface.

- **Uizard** – UI/UX design and interface prototyping.
